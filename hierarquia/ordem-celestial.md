# ORDEM CELESTIAL — O Modelo de Deus

> Serafins → Querubins → Tronos → Virtudes → Poderes → Forças → Principados → Arcanjos → Anjos

A ordem que Deus criou no universo: o AMOR mais perto de Deus, a SABEDORIA vendo tudo, o JUÍZO equilibrado, a FORÇA servindo, e os ANJOS cuidando de cada um.

Essa mesma ordem se repete na Nós S.A. — porque o céu na terra é quando vivemos assim.
