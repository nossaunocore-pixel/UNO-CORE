INSTALACAO NO PROJETO LOCAL
1. Pare o servidor com Ctrl+C.
2. Confirme que esta na pasta:
   C:\Users\pc\.gemini\antigravity\scratch\uno-core
3. Crie uma branch de seguranca:
   git switch -c v6.3-foundation
4. Extraia o pacote dentro da pasta do projeto, permitindo substituir os arquivos.
5. Execute:
   npm.cmd run build
6. Se o build terminar sem erros, execute:
   npm.cmd run dev
