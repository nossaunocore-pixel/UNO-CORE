# UNO CORE

## Engenharia Oficial da Uno

Repositório oficial do núcleo da Plataforma UNO.

Organização: NOS S.A.

## Missão

Construir uma estrutura capaz de integrar pessoas, organizações, agentes de inteligência artificial, ferramentas, conhecimentos e recursos em um único ecossistema.

## Princípios

- Engenharia antes da implementação.
- Toda decisão relevante deve ser documentada.
- Toda alteração deve ser versionada.
- Nenhuma implementação estrutural sem arquitetura correspondente.
- O conhecimento deve permanecer independente das tecnologias utilizadas.
