# MMK — Mapa Mestre do Conhecimento

O MMK (Mapa Mestre do Conhecimento) é o índice central de toda a documentação da Plataforma UNO.

## Missão

Organizar, relacionar e facilitar a navegação entre todos os documentos oficiais da plataforma.

## Áreas do Conhecimento

- Engenharia Oficial (EOU)
- Decisões Arquiteturais (ADR)
- Banco de Dados (DB)
- APIs
- Interface do Usuário (UI)
- Agentes
- Infraestrutura
- Segurança
- Roadmap
- Módulos

## Princípios

- Existe apenas uma fonte oficial de conhecimento.
- Toda documentação possui um local definido.
- Nenhuma decisão estrutural permanece apenas em conversa.
- O conhecimento é independente da tecnologia utilizada.
