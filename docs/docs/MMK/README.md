# MMK — Mapa Mestre do Conhecimento

> O MMK (Mapa Mestre do Conhecimento) é o índice central da Engenharia Oficial da Plataforma UNO.

---

# Objetivo

Organizar, relacionar e padronizar toda a documentação técnica da Plataforma UNO.

Nenhuma decisão arquitetural, implementação, integração ou módulo deverá existir sem estar relacionado ao MMK.

---

# Princípios

- A documentação precede a implementação.
- Toda decisão relevante deve ser registrada.
- Todo componente possui documentação oficial.
- Toda alteração gera histórico.
- A engenharia é a fonte da verdade da plataforma.

---

# Estrutura Oficial

## Engenharia Oficial (EOU)

Define a arquitetura geral da plataforma.

---

## Architecture Decision Records (ADR)

Registra todas as decisões importantes de arquitetura.

---

## Banco de Dados (DB)

Documentação completa do banco de dados oficial.

Inclui:

- tabelas
- relacionamentos
- índices
- migrations
- políticas
- storage

---

## APIs

Documentação das APIs internas e externas.

Inclui:

- endpoints
- autenticação
- contratos
- versionamento

---

## Interface (UI)

Define a arquitetura da interface.

Inclui:

- Design System
- Componentes
- Fluxos
- Navegação
- Experiência do Usuário

---

## Agentes

Documentação oficial dos agentes inteligentes da UNO.

Inclui:

- responsabilidades
- contexto
- memória
- ferramentas
- permissões

---

## Módulos

Cada funcionalidade da plataforma possuirá documentação própria.

Exemplos:

- Zelo
- Mordomo
- Financeiro
- Saúde
- Educação
- Jurídico
- Empresa
- Família

---

# Fluxo Oficial de Engenharia

Toda funcionalidade seguirá obrigatoriamente esta sequência:

1. Ideia
2. Engenharia
3. Documentação
4. Aprovação
5. Implementação
6. Testes
7. Publicação
8. Versionamento

---

# Regra Fundamental

Nenhuma implementação poderá existir sem documentação correspondente.

O MMK é a porta de entrada oficial para todo o conhecimento da Plataforma UNO.
