# 026 — Planejamento

## Objetivo

Definir como a EVA auxilia na organização dos caminhos para alcançar objetivos.

---

## Conceito

Planejamento representa a organização estruturada das ações necessárias para atingir determinado objetivo.

Na Plataforma UNO, o planejamento deverá permanecer flexível, permitindo adaptações sempre que o contexto se modificar.

---

## Componentes

O planejamento poderá incluir:

- metas;
- etapas;
- prioridades;
- recursos;
- prazos;
- indicadores.

---

## Evolução

Todo planejamento deverá ser continuamente revisado conforme novas informações surgirem.

---

## Princípio

Planejar significa preparar-se para evoluir.
