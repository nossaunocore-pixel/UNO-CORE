# EOU-V17 — Governança

> Este volume documenta a governança técnica, operacional e institucional da Plataforma UNO.

---

## Finalidade

Definir responsabilidades, níveis de autoridade, processos decisórios, critérios de aprovação, gestão de mudanças e mecanismos de supervisão da plataforma.

A governança deverá preservar a missão, os princípios e a integridade do ecossistema UNO.
