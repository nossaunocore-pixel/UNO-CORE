# EOU-V28 — Entidades

> Este volume documenta o Modelo Universal de Entidades da Plataforma UNO.

---

## Finalidade

Definir todas as categorias de entidades existentes na Plataforma UNO, seus atributos, relacionamentos, ciclos de vida e formas de interação.

As entidades constituem a base estrutural do ecossistema da UNO.
