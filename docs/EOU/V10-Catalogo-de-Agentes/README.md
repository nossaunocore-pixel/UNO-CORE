# EOU-V10 — Catálogo Universal de Agentes

> Este volume documenta o Catálogo Universal de Agentes da Plataforma UNO.

---

## Finalidade

Definir todos os agentes da Plataforma UNO, suas responsabilidades, capacidades, permissões e formas de atuação.

Inclui agentes humanos, artificiais e híbridos.
