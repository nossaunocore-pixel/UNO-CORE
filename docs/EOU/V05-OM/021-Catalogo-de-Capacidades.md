# 021 — Catálogo de Capacidades

## Objetivo

Estabelecer o Catálogo de Capacidades como a base oficial utilizada pelo OM para localizar competências disponíveis na Plataforma UNO.

---

## Conceito

O Catálogo de Capacidades constitui um inventário vivo das competências existentes no ecossistema.

Ele registra quais entidades, agentes, especialistas, dispositivos e serviços são capazes de executar determinadas atividades.

Sempre que uma operação for iniciada, o OM consultará esse catálogo para identificar a melhor composição de recursos.

---

## Organização

Cada capacidade poderá possuir:

- identificação;
- descrição;
- categoria;
- nível de especialização;
- recursos habilitados;
- requisitos;
- restrições;
- histórico de utilização.

---

## Atualização

O catálogo deverá evoluir continuamente conforme novas capacidades forem incorporadas ao ecossistema.

---

## Princípio

Conhecer as capacidades disponíveis é condição essencial para uma boa orquestração.
