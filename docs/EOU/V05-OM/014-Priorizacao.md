# 014 — Priorização

## Objetivo

Definir os critérios utilizados pelo OM para determinar a ordem de execução das operações.

---

## Conceito

Nem todas as operações possuem a mesma importância ou urgência.

O OM analisa continuamente prioridades considerando contexto, impacto, riscos, dependências, recursos disponíveis e objetivos estratégicos.

A priorização poderá ser alterada dinamicamente sempre que o contexto operacional justificar.

---

## Princípio

Priorizar corretamente preserva recursos e amplia resultados.
