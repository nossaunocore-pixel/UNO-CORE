# EOU-V19 — Industrial

> Este volume documenta a arquitetura do domínio Industrial da Plataforma UNO.

---

## Finalidade

Definir os modelos e processos relacionados à indústria, manufatura, produção, manutenção, logística industrial e integração com tecnologias de automação.

Este domínio estabelece como a Plataforma UNO atua em ambientes industriais.
