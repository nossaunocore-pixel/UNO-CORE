# EOU-V36 — Registros de Decisões Arquiteturais (ADR)

> Este volume documenta as diretrizes oficiais para os Registros de Decisões Arquiteturais da Plataforma UNO.

---

## Finalidade

Estabelecer os critérios para criação, manutenção e rastreabilidade das decisões arquiteturais tomadas durante a evolução da plataforma.

Os ADRs preservam o histórico técnico e os fundamentos de cada decisão relevante.
