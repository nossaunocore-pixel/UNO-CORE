# EOU-V02 — Arquitetura Oficial da UNO

> Este volume define a arquitetura oficial da Plataforma UNO.

---

## Finalidade

Documentar os princípios arquiteturais, camadas, componentes, padrões e relações que estruturam a Plataforma UNO.

---

## Estado

Em desenvolvimento.


## Fronteiras com os fundamentos

V02 documenta camadas, componentes, fronteiras e relações arquiteturais. Não substitui os princípios normativos de V01, o meta-modelo conceitual de V03 nem os contratos dos volumes de domínio. A precedência entre esses tipos de documento está registrada como proposta não aprovada no [ADR-EOU-002](../V36-ADR/ADR-EOU-002-precedencia-documental.md).
