# EOU-V25 — Financeiro

> Este volume documenta o domínio Financeiro da Plataforma UNO.

---

## Finalidade

Definir os modelos financeiros da plataforma, incluindo ativos, passivos, receitas, despesas, investimentos, pagamentos, patrimônio e sustentabilidade econômica.

Este domínio estabelece as bases para a gestão financeira do ecossistema UNO.
