# 007 — Entidades Organizacionais

## Objetivo

Definir os elementos que podem participar de uma organização.

---

## Conceito

Uma organização é formada por entidades cooperando.

Entre elas:

- Pessoas
- Agentes
- Assistentes
- Equipes
- Organizações
- Sistemas

Todos representam participantes organizacionais.

---

## Princípio

Toda organização é composta por entidades que compartilham responsabilidades.
