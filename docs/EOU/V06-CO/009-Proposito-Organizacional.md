# 009 — Propósito Organizacional

## Objetivo

Definir o propósito como elemento central de qualquer organização.

---

## Conceito

Toda organização nasce para cumprir um propósito.

Estruturas existem para servi-lo.

Jamais para substituí-lo.

---

## Princípio

Quando uma organização perde seu propósito, perde também sua identidade.
