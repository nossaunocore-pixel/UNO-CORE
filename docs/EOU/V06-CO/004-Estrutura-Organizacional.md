# 004 — Estrutura Organizacional

## Objetivo

Definir a estrutura básica que organiza qualquer instituição dentro da Plataforma UNO.

---

## Conceito

A Estrutura Organizacional representa a forma como capacidades são distribuídas para cumprir objetivos comuns.

Ela organiza responsabilidades.

Jamais limita potencial.

---

## Componentes

- Organizações
- Unidades
- Departamentos
- Equipes
- Funções
- Responsabilidades
- Autoridades

Cada elemento coopera para formar um único organismo organizacional.

---

## Princípio

Uma boa estrutura não cria burocracia.

Ela reduz complexidade.
