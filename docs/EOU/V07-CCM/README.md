# EOU-V07 — CCM — Central de Coordenação de Missões

> Este volume documenta a Central de Coordenação de Missões (CCM) da Plataforma UNO.

---

## Finalidade

Definir os processos de planejamento, distribuição, acompanhamento e encerramento das missões executadas pela Plataforma UNO.

A CCM coordena pessoas, agentes, recursos e serviços envolvidos em cada missão.
