# EOU-V08 — OPS — Sistema Universal de Missões

> Este volume documenta o Sistema Universal de Missões (OPS) da Plataforma UNO.

---

## Finalidade

Definir o modelo universal de missões da Plataforma UNO, estabelecendo como necessidades são transformadas em planejamento, execução, acompanhamento e resultados.

O OPS integra entidades, capacidades, recursos e agentes durante todo o ciclo operacional.
