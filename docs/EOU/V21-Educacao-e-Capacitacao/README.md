# EOU-V21 — Educação e Capacitação

> Este volume documenta o domínio de Educação e Capacitação da Plataforma UNO.

---

## Finalidade

Definir os modelos de aprendizagem, desenvolvimento de competências, certificações, trilhas de conhecimento e evolução contínua de pessoas e organizações.

A educação é tratada como um processo permanente de desenvolvimento de capacidades.
