# 35 — Dependências

## Objetivo

Definir como entidades dependem umas das outras para existir, operar ou evoluir.

---

## Conceito

Dependência representa uma necessidade funcional entre entidades.

Ela poderá ser permanente ou temporária.

---

## Exemplos

Uma Missão depende de Objetivos.

Um Projeto depende de Recursos.

Uma Organização depende de Pessoas.

Um Agente depende de Capacidades.

Uma Interface depende de Serviços.

---

## Independência

Sempre que possível, a Engenharia Oficial deverá minimizar dependências excessivas.

---

## Evolução

Dependências poderão surgir, modificar-se ou desaparecer durante o ciclo de vida das entidades.
