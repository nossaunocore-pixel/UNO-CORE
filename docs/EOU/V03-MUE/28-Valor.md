# 28 — Valor

## Objetivo

Definir o conceito universal de valor dentro da Plataforma UNO.

---

## Conceito

Valor representa o benefício produzido por uma entidade para outras entidades ou para o ecossistema.

Valor não se restringe ao aspecto financeiro.

Pode assumir diversas formas.

---

## Exemplos

- conhecimento;
- tempo;
- saúde;
- segurança;
- educação;
- dinheiro;
- confiança;
- colaboração;
- inovação;
- bem-estar.

---

## Produção de Valor

Toda entidade poderá:

- produzir;
- consumir;
- compartilhar;
- preservar;
- transformar valor.

---

## Importância

A geração de valor constitui um dos principais indicadores da contribuição de uma entidade para a Plataforma UNO.
