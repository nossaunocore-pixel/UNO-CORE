# 05 — Relacionamentos

## Objetivo

Definir como entidades estabelecem vínculos entre si dentro da Plataforma UNO.

Relacionamentos representam conexões permanentes ou temporárias entre entidades.

---

## Conceito

Nenhuma entidade existe isoladamente.

Todo elemento do ecossistema estabelece algum tipo de relacionamento com outras entidades.

---

## Características

Todo relacionamento deverá possuir:

- origem;
- destino;
- tipo;
- contexto;
- data de início;
- situação;
- histórico.

---

## Exemplos

Uma Pessoa pertence a uma Família.

Uma Organização administra um Projeto.

Um Agente executa uma Missão.

Um Recurso apoia uma Capacidade.

Um Evento altera o Estado de uma Entidade.

---

## Evolução

Relacionamentos poderão ser criados, modificados, suspensos ou encerrados durante o ciclo de vida das entidades envolvidas.

Toda alteração deverá permanecer registrada.
