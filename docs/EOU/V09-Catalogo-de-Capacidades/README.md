# EOU-V09 — Catálogo Universal de Capacidades

> Este volume documenta o Catálogo Universal de Capacidades da Plataforma UNO.

---

## Finalidade

Definir e organizar todas as capacidades humanas, artificiais, institucionais e operacionais disponíveis na Plataforma UNO.

As capacidades representam aquilo que uma entidade pode realizar.
