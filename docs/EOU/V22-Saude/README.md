# EOU-V22 — Saúde

> Este volume documenta o domínio de Saúde da Plataforma UNO.

---

## Finalidade

Definir os modelos, processos e integrações relacionados à promoção da saúde, prevenção, acompanhamento e bem-estar das pessoas.

O domínio considera aspectos físicos, mentais, sociais e preventivos da saúde.
