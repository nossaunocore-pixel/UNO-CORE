## ✨ O QUE É A UNO

A **Uno** não é apenas um sistema. É uma **forma de ver o mundo e de viver a tecnologia**. Nasceu do desejo de construir algo que sirva, nunca que domine. Que una, nunca que divida. Que proteja a dignidade de cada pessoa, acima de qualquer lucro, poder ou interesse.

A Uno existe **enquanto servir ao bem comum**. Se um dia deixar de servir — extinguir-se-á com alegria.
